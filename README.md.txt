# Digital Twin - Pre-Manufacture Vehicle Testing

This project creates a Digital Twin simulation to test a vehicle virtually before manufacturing.

## What I Did
- Built a virtual model of the vehicle
- Simulated acceleration, braking, and engine temperature tests
- Analyzed the results to find problems before production
- Reduced cost and errors by testing virtually

## Tools Used
- Python
- Simulation

## How to Run
```bash
python main.py
